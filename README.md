# 化学世界 · 雅集

一个纯前端的古风化学学习工具：**查得到、算得准、练得够**。
无需后端、无需构建，双击 `index.html` 即可使用。

---

### 收藏

**元素详情、分子、方程式、原子团、酸碱、有机反应、速查表每一行、配平结果**右侧都有一枚 ☆，
点一下即收藏、再点取消，全站状态同步（同一物质在检索页与来源页显示为同一个收藏）。

「数据库 · 收藏夹」里可以按类别筛选、夹内搜索，看到收藏时间，并一键「前往」原始页面；
数据存在本机 `localStorage`（上限 400 条），可导出 JSON 备份。

首页提供快捷检索框与八宫格导览，回车即跳转到数据库并带上关键词。
界面为深墨底 + 鎏金的卷轴风格，适配桌面与手机，支持 `prefers-reduced-motion`。

支持 `index.html#acidbase` 这样的锚点直达任意板块，也可用 `#lab~bench`、`#acidbase~table`
直接定位到某个子标签。

## 快速开始

**方式一（推荐，可读取最新 txt）**

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

**方式二（直接双击 `index.html`）**

浏览器出于安全策略会拦截 `file://` 下的 `fetch`，此时页面自动改用 `db.js` 离线快照——
数据与 txt 完全一致，只是修改 txt 后需要重新生成快照（见下）。

## 扩充数据

所有数据都是**逗号分隔的纯文本表格**，首行为表头，含逗号的字段用英文双引号包裹。
改完任意 txt 后执行：

```bash
node tools/build_db.js     # 重新生成 db.js（打印每个文件的条数与格式警告）
node tools/test_core.js    # 回归测试：解析、配平、分子量
```

字段定义见 `tools/build_db.js` 顶部的 `SCHEMAS`。

## 配平引擎说明

1. **解析**：支持 `Ca3(PO4)2`、`K4[Fe(CN)6]`、`CuSO4·5H2O`、`MnO4-`、`SO4^2-`、`Fe3+`、`SO₄²⁻`、
   状态符号 `(aq)`、全角 `＋＝`，以及 `CH2=CH2` 中的双键（不会被误认作箭头）。
2. **求解**：把每种元素与电荷写成线性方程组，用**精确有理数高斯消元**求零空间，
   再在零空间内搜索全正整数解（按系数和从小到大排序）。
3. **多解消歧**：像 `KMnO4 + H2O2 + H2SO4 → ...` 这类式子仅凭元素守恒无法唯一确定系数。
   引擎用「物种指纹」（元素组成 + 电荷，忽略书写顺序与下标形式）在方程式库中反查，
   命中则采用库中的真实系数；未命中会**列出全部可行解**并提示需结合反应机理判断，
   不静默给出一组可能有化学错误的答案。
4. **诊断**：未知元素、括号不匹配、某元素只在一侧、缺箭头、电荷不守恒等都有针对性提示。

## 说明

- 分子量默认使用精确原子量，可切换为教材近似值（Cl 取 35.5、Fe 取 56 等）。
- pH 计算按 25 ℃、Kw = 1×10⁻¹⁴；弱酸 / 弱碱用电荷平衡方程数值求解，不依赖近似公式。
- 加聚、缩聚等含聚合度 n 的式子仅作展示，不参与配平。
