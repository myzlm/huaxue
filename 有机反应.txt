类型,方程式,条件,描述
取代反应,CH₄ + Cl₂ → CH₃Cl + HCl,光照,甲烷氯代第一步；产物中四种氯代物共存
取代反应,C₆H₆ + Br₂ → C₆H₅Br + HBr,FeBr₃催化,苯的溴代；只生成一溴代物
取代反应,C₆H₆ + HNO₃ → C₆H₅NO₂ + H₂O,浓硫酸 55至60摄氏度,苯的硝化；引入硝基
取代反应,C₆H₅OH + 3Br₂ → C₆H₂Br₃OH + 3HBr,无需催化剂,苯酚与溴水生成白色三溴苯酚沉淀
取代反应,CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O,浓硫酸 加热,酯化反应；可逆；硫酸兼催化与吸水
取代反应,2C₆H₅OH + 2Na → 2C₆H₅ONa + H₂,常温,酚羟基氢与钠反应放出氢气
加成反应,CH₂=CH₂ + Br₂ → CH₂BrCH₂Br,常温,溴水褪色；检验碳碳双键
加成反应,CH₂=CH₂ + H₂ → C₂H₆,Ni催化 加热,乙烯加氢得乙烷
加成反应,CH₂=CH₂ + H₂O → C₂H₅OH,磷酸催化 加热加压,工业制乙醇（水合）
加成反应,CH≡CH + 2Br₂ → CHBr₂CHBr₂,常温,乙炔与溴充分加成
加成反应,C₆H₆ + 3H₂ → C₆H₁₂,Ni催化 加压加热,苯加氢得环己烷
加成反应,CH₃CHO + H₂ → C₂H₅OH,Ni催化 加热,醛的催化加氢（还原）
消去反应,C₂H₅OH → CH₂=CH₂ + H₂O,浓硫酸 170摄氏度,实验室制乙烯；140摄氏度则生成乙醚
消去反应,CH₃CH₂Br + NaOH → CH₂=CH₂ + NaBr + H₂O,NaOH醇溶液 加热,卤代烃消去；水溶液则水解成醇
氧化反应,2C₂H₅OH + O₂ → 2CH₃CHO + 2H₂O,Cu或Ag催化 加热,醇的催化氧化；断羟基氢与阿尔法氢
氧化反应,2CH₃CHO + O₂ → 2CH₃COOH,催化剂 加热,乙醛氧化成乙酸
氧化反应,CH₃CHO + 2Ag(NH₃)₂OH → CH₃COONH₄ + 2Ag + 3NH₃ + H₂O,水浴加热,银镜反应；检验醛基
氧化反应,CH₃CHO + 2Cu(OH)₂ → CH₃COOH + Cu₂O + 2H₂O,加热煮沸,砖红色沉淀；斐林反应
氧化反应,CH₂=CH₂ + O₂ → 2CH₃CHO,银催化 加热,乙烯催化氧化
氧化反应,C₆H₁₂O₆ + 2Ag(NH₃)₂OH → C₆H₁₂O₇ + 2Ag + 4NH₃ + H₂O,水浴加热,葡萄糖的银镜反应；果糖也能反应
氧化反应,2KMnO₄ + 5H₂C₂O₄ + 3H₂SO₄ → K₂SO₄ + 2MnSO₄ + 10CO₂ + 8H₂O,加热,草酸滴定高锰酸钾；自身指示剂
水解反应,CH₃COOC₂H₅ + H₂O ⇌ CH₃COOH + C₂H₅OH,稀硫酸 加热,酯的酸性水解；可逆
水解反应,CH₃COOC₂H₅ + NaOH → CH₃COONa + C₂H₅OH,加热,酯的碱性水解即皂化；不可逆
水解反应,C₁₂H₂₂O₁₁ + H₂O → C₆H₁₂O₆ + C₆H₁₂O₆,酸或酶催化,蔗糖水解；生成葡萄糖与果糖
水解反应,(C₆H₁₀O₅)ₙ + nH₂O → nC₆H₁₂O₆,酸或酶催化,淀粉水解；最终产物葡萄糖
加聚反应,nCH₂=CH₂ → (C₂H₄)ₙ,催化剂 加热加压,聚乙烯；塑料与薄膜
加聚反应,nCH₂=CHCH₃ → (C₃H₆)ₙ,催化剂,聚丙烯；编织袋与汽车部件
加聚反应,nCH₂=CHCl → (C₂H₃Cl)ₙ,催化剂,聚氯乙烯；管材与电线护套
加聚反应,nCH₂=CHCH=CH₂ → (C₄H₆)ₙ,催化剂,聚丁二烯；合成橡胶
缩聚反应,nHOCH₂CH₂OH + nHOOC-C₆H₄-COOH → 聚酯 + 2nH₂O,催化剂 加热,涤纶；酯键连接
燃烧反应,CH₄ + 2O₂ → CO₂ + 2H₂O,点燃,甲烷完全燃烧；淡蓝色火焰
燃烧反应,C₂H₅OH + 3O₂ → 2CO₂ + 3H₂O,点燃,乙醇完全燃烧
燃烧反应,2C₂H₂ + 5O₂ → 4CO₂ + 2H₂O,点燃,氧炔焰用于焊接切割
燃烧反应,C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O,酶催化,细胞呼吸；释放能量
裂解反应,C₁₆H₃₄ → C₈H₁₈ + C₈H₁₆,高温催化,石油裂化提高汽油产量
