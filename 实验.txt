实验名称,现象,结论或方程式,注意事项
氢气在空气中燃烧,淡蓝色火焰 烧杯内壁出现水雾,2H2 + O2 → 2H2O,点燃前必须检验纯度
氢气还原氧化铜,黑色粉末变为红色 试管口有水珠,H2 + CuO → Cu + H2O,先通氢气后加热 结束先撤酒精灯
铁丝在氧气中燃烧,火星四射 生成黑色固体,3Fe + 2O2 → Fe3O4,集气瓶底留少量水或细沙
硫在氧气中燃烧,明亮的蓝紫色火焰 生成有刺激性气味的气体,S + O2 → SO2,瓶底留水以吸收SO₂
木炭在氧气中燃烧,发出白光 生成使石灰水变浑浊的气体,C + O2 → CO2,燃烧匙应自上而下缓慢伸入
镁条在空气中燃烧,耀眼白光 生成白色固体,2Mg + O2 → 2MgO,不可直视 防止灼伤眼睛
红磷燃烧测定空气中氧气含量,产生大量白烟 水面上升约五分之一,4P + 5O2 → 2P2O5,装置气密性要好 冷却后再读数
电解水,两极均有气泡 正氧负氢体积比约1比2,2H2O →(通电) 2H2↑ + O2↑,加少量硫酸钠增强导电性
一氧化碳还原氧化铁,红棕色粉末变黑 尾气燃烧呈蓝色,Fe2O3 + 3CO → 2Fe + 3CO2,尾气必须点燃处理 防止中毒
甲烷的燃烧,淡蓝色火焰 干冷烧杯有水雾 石灰水变浑浊,CH4 + 2O2 → CO2 + 2H2O,点燃前必须验纯
钠与水的反应,钠浮在水面熔成小球四处游动 溶液变红,2Na + 2H2O → 2NaOH + H2↑,钠保存在煤油中 取用动作要快
铝与氢氧化钠溶液反应,产生气泡 铝逐渐溶解,2Al + 2NaOH + 2H2O → 2NaAlO2 + 3H2↑,反应放热 注意通风与防护
钠在氯气中燃烧,剧烈燃烧 生成白色固体,2Na + Cl2 → 2NaCl,氯气有毒 须在通风橱中进行
氯化铁的水解,溶液呈棕黄色 加热颜色加深,Fe3+ + 3H2O ⇌ Fe(OH)3 + 3H+,加酸可抑制水解
碳酸钠与盐酸反应,剧烈产生气泡,Na2CO3 + 2HCl → 2NaCl + H2O + CO2↑,滴加顺序不同现象也不同
碳酸氢钠受热分解,试管口有水珠 石灰水变浑浊,2NaHCO3 → Na2CO3 + H2O + CO2↑,常用于鉴别碳酸钠与碳酸氢钠
氢氧化铝的两性,白色沉淀既溶于强酸也溶于强碱,Al(OH)3 + NaOH → NaAlO2 + 2H2O,必须是新制氢氧化铝
氢氧化亚铁的制备,白色沉淀迅速变灰绿最终变红褐,4Fe(OH)2 + O2 + 2H2O → 4Fe(OH)3,需隔绝空气 使用煮沸过的水
银镜反应,试管内壁附着光亮的银,CH3CHO + 2Ag(NH3)2OH → CH3COONH4 + 2Ag↓ + 3NH3 + H2O,水浴加热 不可振荡
醛与新制氢氧化铜反应,生成砖红色沉淀,CH3CHO + 2Cu(OH)2 → CH3COOH + Cu2O↓ + 2H2O,必须加热至沸腾
酯化反应,生成有果香味的油状液体,CH3COOH + C2H5OH ⇌ CH3COOC2H5 + H2O,浓硫酸催化吸水 导管不插入液面
苯的溴代反应,液体分层 上层呈橙红色,C6H6 + Br2 → C6H5Br + HBr,需铁粉催化 实际催化剂为FeBr3
乙烯使溴水褪色,溴水颜色褪去,CH2=CH2 + Br2 → CH2BrCH2Br,加成反应 可用于区别甲烷与乙烯
乙烯使酸性高锰酸钾褪色,紫色褪去,—,氧化反应 也能区别甲烷与乙烯
蛋白质的盐析,加入浓硫酸铵溶液后析出沉淀,—,可逆 加水后沉淀重新溶解
蛋白质的变性,加热或加重金属盐后产生沉淀,—,不可逆 可用于杀菌消毒
淀粉的水解,加碘水不再变蓝 与氢氧化铜共热出现砖红色沉淀,—,稀硫酸催化 需先中和再加氢氧化铜
焰色反应,钠呈黄色 钾呈紫色 钙呈砖红色 钡呈黄绿色,—,用铂丝或铁丝 每次灼烧至火焰无色
渗析,半透膜内大分子被保留 小分子和离子透出,—,用于提纯胶体
丁达尔效应,光束通过胶体时出现明亮的通路,—,用于区别胶体与溶液
配制一定物质的量浓度的溶液,—,—,定容时视线与刻度线平齐 摇匀后浓度均匀
酸碱中和滴定,指示剂在终点时变色,—,滴定管需用待装液润洗 眼睛注视锥形瓶内颜色变化
铁钉置换铜,铁钉表面覆盖红色物质 蓝色溶液逐渐变浅,Fe + CuSO4 → FeSO4 + Cu,硫酸铜溶液不宜过浓
